A one-line entry for make.fun's "The Meeting That Should Have Been One Line" bounty.

`main.py` writes a single sentence to `/output/entry.txt` — the sentence that
could have replaced an entire pointless meeting. The line is self-referential:
it *is* the email the meeting should have been, so the moment it is read,
the meeting is already over.
